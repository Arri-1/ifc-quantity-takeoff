# IFC Quantity Takeoff

An automated Quantity Takeoff (QTO) script built in Python using IfcOpenShell to extract material volumes from BIM models.

## Sample Data Credit
The sample model used in this project (`Building-Structural.ifc`) is provided by buildingSMART from their Sample-Test-Files GitHub repository.
